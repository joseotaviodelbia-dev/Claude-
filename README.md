# Claude-

Streams a Grok response with the [AI SDK](https://ai-sdk.dev) `streamText`, through [OpenRouter](https://openrouter.ai).

```sh
npm install
cp .env.example .env   # add your OPENROUTER_API_KEY
npm start
```

Set `OPENROUTER_MODEL` to use a different OpenRouter model slug (default `x-ai/grok-4.7`).
